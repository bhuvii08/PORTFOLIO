# Portfolio Website

A responsive, single-page personal portfolio for Bhoomika Singh, built with plain HTML, CSS, and JavaScript.

## Live Demo

- https://bhuvii08.github.io/PORTFOLIO/

## Highlights

- Clean and modern one-page layout
- Mobile-friendly navigation
- Section-based smooth scrolling
- Scroll progress indicator
- Typing animation in hero section
- Reveal-on-scroll and hover tilt effects
- Resume download integration

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (CDN)
- Google Fonts (Manrope, Space Grotesk)

## Project Structure

```text
portfolio/
|- index.html
|- style.css
|- script.js
|- favicon.svg
|- bhoomika.pdf
|- images/
|  |- profile.jpg
|- README.md
```

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/bhuvii08/PORTFOLIO.git
   cd PORTFOLIO
   ```

2. Open `index.html` directly in your browser.

Optional: use VS Code Live Server for auto-reload during edits.

## Quick Customization

- Update personal details and section content in `index.html`
- Adjust colors, spacing, and animations in `style.css`
- Modify interactions and effects in `script.js`
- Replace assets in `images/` and update `bhoomika.pdf`

## Deployment

This project can be deployed easily on GitHub Pages, Netlify, or Vercel as a static site.

For GitHub Pages, set source to `Deploy from a branch` and select `main` / `root`.
